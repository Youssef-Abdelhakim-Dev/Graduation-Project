# 🎓 E-Learning Platform

> A **full-stack e-learning web application** that connects **doctors and students** through interactive content, lectures, and communication tools — built using **PHP**, **MySQL**, and **modern front-end technologies**.  
> Designed with **3D-inspired gradients**, **complex CSS animations**, and a **responsive modern UI**.

## 🧠 Overview

This E-learning Platform empowers educators and learners through:
- 🧩 Interactive course modules  
- 🎥 Embedded video lectures  
- 🗣️ Real-time feedback and Q&A  
- 📜 PDF lecture notes  
- 💾 Secure authentication and data storage  
- 🎨 Dynamic, gradient-based animated UI  

---

## 🧱 Tech Stack

| Layer | Technologies |
|-------|---------------|
| 🎨 **Frontend** | HTML5, CSS3, JavaScript (ES6+), GSAP, TinyMCE, PDF.js, YouTube Iframe API, MediaDevices API |
| 🐘 **Backend** | PHP (XAMPP Stack), MySQL | Composer
| 🔄 **Communication** | AJAX, Axios |
| 🧰 **Version Control & Deployment** | Git, GitHub
| 💡 **Template Engine** | Twig *(Reusable components for views)* |

---

## ⚙️ Installation & Local Setup

### 🧩 Requirements
- PHP ≥ 8.0  
- MySQL ≥ 5.7  
- XAMPP (recommended for local development)  
- Composer (for PHP dependencies)  
- Node.js (for front-end build tools, optional)
